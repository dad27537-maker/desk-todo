# 截图翻译窗口

此页面覆盖 MASTER.md 中面向网页的字体和布局建议。实现是原生 Win32 桌面窗口，
使用系统字体与 RichEdit，不加载网页、远程字体或图片素材。

## 视觉规范

| 项目 | 约定 |
| --- | --- |
| 窗口背景 | `#F0F9F6`，低饱和薄荷色 |
| 内容表面 | 白色，14 DIP 圆角，细描边与轻阴影 |
| 主要文字 | `#193933` |
| 次要文字 | `#5C706A` |
| 青绿强调 | `#0F766E`，用于图标、焦点和次级动作 |
| 主要操作 | `#C2410C` 配白字，保持文字对比度 |
| 字体 | Microsoft YaHei UI；标题 25 DIP，正文 16 DIP，说明 12–13 DIP |
| 图标 | 同一套本地矢量笔画，圆角端点，不使用 emoji |
| 动效 | 悬停约 150 ms；遵循 Windows 客户区动画设置 |

布局顺序为标题与隐私提示、语言工具栏、并排原译文阅读区、截图预览与辅助操作、
状态栏。两侧文字起点对齐。复制按钮归属各自阅读区，双语复制位于底部辅助区。
内容宽度随窗口缩放，最小窗口为 840 × 640 DIP；长文本在阅读区内部滚动。

## 状态与交互

- 加载时展示文字提示与进度图标，保留可读原文，取消始终可用。
- 成功时显示完成反馈、字数和可复制结果。
- 失败时保留原文，提供明确错误与重试按钮。
- 键盘焦点必须可见，`Ctrl + Enter` 触发翻译；忙碌时 Esc 取消，空闲时 Esc 关闭。
- 原生语言下拉菜单保留键盘导航；辅助操作提供悬停提示。
- 颜色、字体、几何与矢量图标集中在 `TranslationWindowTheme.h`，任务与编辑状态仍由
  `TranslationWindow.cpp` 管理。

## 视觉验证

`DeskTodoTranslationWindowSmoke` 默认运行交互回归。使用 `--preview`、
`--preview-compact`、`--preview-loading`、`--preview-error` 可渲染对应场景；
通过 `DESKTODO_TRANSLATION_PREVIEW` 指定 BMP 路径。预览均使用合成图片与模拟译文，
不能视为线上翻译准确率证据。2026-10-28 已在真实 Windows 桌面、150% DPI 下检查。
