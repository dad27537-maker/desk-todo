# 代码审核与修复记录（2026-11-04）

本轮重点审核当前改动及其调用路径：截图、桌面图标启动恢复、局域网快传、OCR、翻译窗口，并检查配置恢复和文件移动相关代码。保留工作区已有功能改动。

## 已修复的问题

| 问题 | 原因与处理 |
| --- | --- |
| 截图拖动中保存，取消后选区仍跟随鼠标；导出的标注可能错位 | 原先先生成图片、再进入保存状态，释放鼠标时的收尾消息被保存状态拦截。现在先结束拖动、提交标注偏移，再生成图片和打开保存框。复制、贴图和识别出口同样受益。 |
| 快速拖动或绘制时，终点停留在最后一次移动消息的位置 | 鼠标抬起的位置可能更新。现在抬起时先应用最终坐标，再结束移动或绘制。 |
| 快传上传截断已有的同名 `.desktodo-part` 文件 | 改为带唯一后缀的临时文件，并用 `CREATE_NEW` 原子创建；失败、中断和异常时自动释放句柄并清理本次临时文件。 |
| 上传尚未结束时，其他程序创建的同名目标可能被覆盖 | 最终提交改用不覆盖目标的 `MoveFileW`，冲突返回失败并保留已有目标文件。 |
| 接收目录异常或磁盘操作异常可能导致应用退出 | 启动失败时回收监听套接字与网络初始化状态；后台请求处理捕获异常，避免异常逃逸线程。写入失败立即停止接收并清理临时文件。 |
| 分段接收请求头时可能放过超过 64 KiB 的完整请求头 | 除接收循环限额外，再校验找到的完整请求头长度，超限返回 431。 |

实现位于 `DeskTodo.Next/src/Window/ScreenshotTool.cpp` 和 `DeskTodo.Next/src/Window/LanTransferWindow.cpp`；对应回归位于 `DeskTodo.Next/tests/screenshot-ocr-smoke.cpp` 与 `DeskTodo.Next/tests/lan-transfer-smoke.cpp`。
